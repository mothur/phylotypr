# Package index

## Functions

The functions needed to train the naive Bayesian classifier and run it
on an unknown sequence

- [`build_kmer_database()`](https://mothur.org/phylotypr/reference/build_kmer_database.md)
  : Build kmer database
- [`create_database()`](https://mothur.org/phylotypr/reference/create_database.md)
  : Build custom database object for use with phylotypr
- [`classify_sequences()`](https://mothur.org/phylotypr/reference/classify_sequences.md)
  : Classify a vector of 16S rRNA gene sequence fragments
- [`classify_sequence()`](https://mothur.org/phylotypr/reference/classify_sequence.md)
  : Classify 16S rRNA gene sequence fragment
- [`filter_taxonomy()`](https://mothur.org/phylotypr/reference/filter_taxonomy.md)
  : Filter taxonomy
- [`print_taxonomy()`](https://mothur.org/phylotypr/reference/print_taxonomy.md)
  : Print taxonomy for an unknown sequence
- [`read_fasta()`](https://mothur.org/phylotypr/reference/read_fasta.md)
  : Read in a FASTA-formatted file containing DNA sequences
- [`write_fasta()`](https://mothur.org/phylotypr/reference/write_fasta.md)
  : Write to a FASTA-formatted file
- [`read_taxonomy()`](https://mothur.org/phylotypr/reference/read_taxonomy.md)
  : Read in taxonomy files
- [`phylotypr_example()`](https://mothur.org/phylotypr/reference/phylotypr_example.md)
  : Get path to phylotypr example
